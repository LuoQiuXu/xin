2. FROZEN TRAINING PROTOCOL
============================================================

Use the protocol file as the source of truth. Key settings:

Datasets:
- ImageNet-LT, 1,000 classes.
- Places-LT, 365 classes.

Seeds:
- 123, 124, 125.
- Each dataset/seed pair gets its own independently trained Stage-I backbone.
- D0/D1/D2 for that dataset/seed share the exact same Stage-I checkpoint, feature cache, initial classifier, class counts, and sampling plan.

Stage I, six independent runs:
- torchvision ResNet-50, weights=None, random initialization.
- 2,048-D pooled feature; linear classifier.
- 224 x 224.
- 90 fixed epochs.
- Batch size 16.
- SGD LR 0.01, momentum 0.9, weight decay 0.0002, Nesterov false.
- Five-epoch linear warm-up then cosine decay to zero.
- Instance sampling, CE + MixUp alpha 1.0.
- CUDA AMP; no gradient accumulation.
- Final epoch 90 only; no best-validation selection and no early stopping.
- Same architecture and initialization policy on both datasets. This is a controlled transfer setup, not a claim to reproduce official H2T ImageNet/Places training recipes.

Stage-II, eighteen runs:
- Freeze Stage-I backbone and all BN buffers.
- Extract deterministic center-crop 2,048-D float32 train features once per dataset/seed.
- Train only a linear classifier for 30 epochs.
- Batch size 64, SGD LR 0.01, momentum 0.9, weight decay 0.0002, FP32.
- No MixUp, no image augmentation, no gradient accumulation.
- Use the pinned official CC-SAM sampler at:
  H2T_repro_audit/ccsam_stage2_controlled_cifar100_20261106/official_reference/Samplers.py
  Expected SHA256:
  c84dfcb46c747a2ed1131df533184b2f9bf1724bc855a3d774830e795f60e174
- One stored sampling plan per dataset/seed; exactly N_train indices per epoch; same plan across D0/D1/D2.
- Class weights: log(max_count / count_c + 0.01) / 2.0.
- alpha(epoch) = min((epoch + 1) / 30, 0.3).
- D0: alpha * mean(weighted clean CE) + (1-alpha) * mean(clean CE); delta exactly zero.
- D1: same as C1, with full class-conditional feature-gradient delta and weighted adversarial CE.
- D2: full D1 objective + Many-only KL from matching D0 teacher; T=2, lambda=1; Many means TRAIN count strictly >100; KL outputs cover all classes; teacher/student logits use clean features; teacher frozen.
- D2 student starts from Stage-I classifier, not D0 final weights.

Evaluation:
- Fixed Stage-I epoch 90 and Stage-II epoch 30.
- Do not select best epoch.
- Only after all 18 Stage-II runs finish, evaluate official test splits once.
- Metrics: Overall, Many, Medium, Few macro accuracy, per-class accuracy, optional Top-5.
- Many >100; Medium 20..100 inclusive; Few <20, based on official TRAIN counts.
- Report mean and sample SD across three independent end-to-end seeds.
- Paired deltas: D1-D0, D2-D0, D2-D1.
- No significance claims with three seeds.

Resource:
- RTX 5070 Laptop, 8 GB VRAM.
- Stage I batch16 + AMP.
- Stage II cached feature batch64 + FP32.
- Default workers4, configurable to 0 for Windows debugging.
- If OOM, stop and report. Do not silently lower resolution, batch size, epochs, or change backbone.
