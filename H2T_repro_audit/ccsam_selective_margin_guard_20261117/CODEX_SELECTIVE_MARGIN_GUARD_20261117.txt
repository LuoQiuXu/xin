SCIENTIFIC GOAL
Run exactly one new candidate arm, D3 = original D1 + selective Many-to-Tail margin guard (SMG), on ImageNet-LT and Places-LT. This is a targeted method iteration, not another mechanism audit.

The hypothesis is that some D1 tail-directed updates reduce useful Many-vs-non-Many decision margins. SMG protects only positive Many-to-non-Many margins already present in the frozen same-dataset/same-seed D0 teacher. It does not match the full teacher distribution.

FIXED OBJECTIVE
Use the already implemented function:
  margin_guard_core.selective_many_tail_margin_guard

D1 remains completely unchanged:
  L_D1 = alpha * mean(w_y * CE(classifier(f + delta), y))
       + (1-alpha) * mean(CE(classifier(f), y))

D3:
  L_D3 = L_D1 + 1.0 * L_SMG

SMG fixed values:
- Many threshold: train_count > 100
- Non-Many outputs: train_count <= 100
- Eligible inputs: true label is Many AND frozen D0 teacher Many-to-non-Many margin > 1e-6
- Retained teacher-margin fraction: 0.5
- Epsilon: 1e-6
- Guard coefficient: 1.0
- Guard logits are computed on clean cached features, not perturbed features.
- Teacher logits are detached; D0 teacher is frozen.
- No D2 KL term is included in D3.
- No parameter residual, no new backbone, no extra expert, no extra loss, no hyperparameter sweep.
