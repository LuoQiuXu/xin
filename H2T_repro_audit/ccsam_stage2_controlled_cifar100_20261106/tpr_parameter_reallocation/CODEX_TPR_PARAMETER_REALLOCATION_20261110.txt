### Residual-space correction and artifact safety

The corrected tail-neighbor diversity term is computed from the effective classifier residual rows Delta W = B @ A, not from B alone. This changes the TPR source/protocol hashes.

Before rerunning:
- If preflight_report.json, smoke_report.json, or tail_neighbor_graph.json already exists from the earlier coefficient-space draft, move each existing file unchanged into archive/pre_residual_space_diversity_fix/ (preserve its original filename). Do not delete or overwrite those artifacts.
- If formal_completed.json or any results/seed_*/CCSAM_TPR output exists from the earlier draft, STOP. Preserve the old run as a coefficient-space variant; do not overwrite it or mix it with corrected residual-space results. Request a separately named run arm before proceeding.
- After archiving stale preflight/Smoke artifacts, rerun syntax tests, preflight, and Smoke from the corrected source. Do not reuse an old preflight or Smoke report because their source hashes describe the earlier implementation.

The method is CC-SAM-TPR:

1. Keep the original validated C1 CC-SAM feature-gradient perturbation and loss unchanged.
2. Use the matching seed's completed C2 classifier as a frozen general classifier.
3. Add a low-rank residual only to non-Many output rows:
       W_t = D_tail B A
4. Apply the MORE class-prior-weighted squared L2 logit discrepancy:
       L_MORE = mean_i[(N_yi/N) * ||z_TPR(f_i)-z_C2(f_i)||_2^2]
5. Apply the MORE sinusoidal schedule:
       alpha_MORE(t) = A sin(pi*t/(T-1))
       A/C = 2.0, C=100, so A=200; T=5100 steps.
6. Address MORE's two Further Discussions:
   - intra-tail competition: class-specific B_c rows and a train-only top-2 clean-GAP neighbor graph with effective residual-row direction separation (Delta W = B @ A);
   - general/tail parameter overlap: soft row-wise orthogonality between W_g[c] and W_t[c] for each non-Many class.
7. Final inference uses one merged classifier. This is not a multi-expert method.

The total objective and all fixed settings are in TPR_PROTOCOL.md. Do not add C4's KL loss: MORE's paper reports better performance from L2 discrepancy than KL for its reallocation objective.

This is a classifier-stage MORE-inspired adaptation, not a full reproduction of MORE's network-wide decomposition. The backbone and C2 classifier remain frozen. Do not claim that dynamic layer-wise decomposition or cross-modal generalization has been solved.

## E. Frozen method and settings

- Dataset: CIFAR-100-LT IF=100, official TRAIN only, 10,847 samples.
- Backbone: sealed Clean Stage-I ResNet-32, seed 42, best epoch 184.
- Feature: existing clean_compatible_gap, 64-D.
- Seeds: 123, 124, 125.
- Base classifier: matching seed's final epoch-30 C2 classifier.
- Trainable parameters: low-rank A and B only.
- Rank: 8.
- Tail output rows: sealed TRAIN count <=100 (all MediumN + Few classes).
- Many output rows: sealed TRAIN count >100; these rows are bitwise fixed to C2.
- C2 classifier bias: frozen.
- Backbone and BN: frozen.
- Batch size: 64; 170 steps/epoch.
- Epochs: 30 per seed.
- Optimizer: SGD(lr=0.01, momentum=0.9, weight_decay=0.0002, nesterov=False).
- Precision: FP32; no AMP, MixUp, gradient accumulation, LR schedule change, or early stopping.
- Sampling plan and augmentation RNG: exactly the existing per-seed sealed plan and C1 continuous augmentation RNG.
- MORE amplitude: A/C=2.0, hence A=200 for C=100. Fixed first-run setting; do not tune.
- Row-wise orthogonality lambda: 0.1.
- Tail-neighbor effective-residual-row diversity lambda: 0.1.
- Tail-neighbor graph: symmetric top-2 cosine neighbors between non-Many clean-GAP TRAIN class centroids only.
- Primary epoch: fixed epoch 30.
- Official CIFAR-100 TEST: strictly prohibited.

Do not add a separate KL distillation term. The MORE L2 discrepancy is the reallocation/preservation term.

Only TPR is newly trained:
- 3 seeds × 30 epochs = 90 epochs.
- 170 steps/epoch.
- 15,300 optimizer steps total.
