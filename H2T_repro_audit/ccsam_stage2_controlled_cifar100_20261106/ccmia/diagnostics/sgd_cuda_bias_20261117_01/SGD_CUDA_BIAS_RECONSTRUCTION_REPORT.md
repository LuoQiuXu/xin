## 结论

原 Smoke 失败精确复现于 **seed 124、epoch 1、batch 0**。偏置参数差的最大绝对残差为 `5.7541080203e-8`，归一化尺度为 `1.0102987289e-5`，原门禁相对误差为 `0.005695452103`。最大残差出现在类别索引 4，该位置的残差有 **99.9931%** 由两个分类头分别写回 FP32 偏置时的舍入解释。该结果符合本轮诊断的情形 A。

## PyTorch SGD 执行路径

Python `3.12.12`，PyTorch `2.14.1+cu132`，CUDA build `13.2`，NVIDIA 驱动 `591.74`，GPU 为 GeForce RTX 5070 Laptop GPU，计算能力 `12.0`。两组 `optimizer.defaults` 均为 `lr=0.01`、`momentum=0.9`、`dampening=0`、`weight_decay=0.0002`、`nesterov=False`、`maximize=False`、`differentiable=False`、`foreach=None`、`fused=None`。

Profiler 在六批均观察到 CUDA `foreach=True`、`fused=False`，CPU `foreach=False`、`fused=False`。首步在耦合权重衰减后复制梯度初始化缓冲，后续按 `v = 0.9 * v_prev + g + 0.0002 * p` 更新缓冲，再按 `p = p - 0.01 * v` 写回。用观测到的原生操作在两设备上分别复算后，C2/C3 的每个参数与缓冲均和各自的 SGD 实测逐元素精确相等。

CPU 与 CUDA 每步从同一组实测的前置参数、动量状态和由同批 GAP 生成的梯度开始，进入优化器前验证张量 SHA256。六批所有参数、所有配对参数差和动量差均逐元素精确相等。仅 seed 123、batch 0 的两个独立偏置缓冲在类 98 各相差 `1.4552e-11`，这一差值在 C3 − C2 中抵消。 [Profiler 和输入指纹](batches.jsonl)

## 尺度自适应判据提案

设 `p[j,t]` 是臂 `j` 在第 `t` 步前读到的 FP32 参数，`v[j,t]` 是本步实际写回的动量缓冲，`η` 为学习率。先在 FP64 计算每一步、每个元素的写回舍入。

```text
r[j,t] = p_stored[j,t+1] - (p[j,t] - η * v[j,t])
R[t] = sum_{k <= t}(r[C3,k] - r[C2,k])
```

对 `r[j,t]` 施加独立的 FP32 舍入上界。取单位舍入误差 `u = 2^-24`、半个最小非正规间距 `s = 2^-150`、`η32 = FP32(η)`。代入该步每个元素的实际操作数得到上界 `B`。

```text
q = |η32 * v|
B_mul = u * q + s
B = |η32 - η| * |v| + B_mul + u * (|p| + q + B_mul) + s
```

这个上界包含系数转换、乘积舍入和加法舍入。在正常 FP32 舍入下也覆盖乘加合并。六批实测的最大单臂 `|r|/B` 为 `0.98891`。失败元素两臂的合计上界为 `8.18958e-8`。

参数重构可先在 FP64 中对两臂已写回参数作差，扣除累计的 `R[t]`，再用 `0.005 × max(||实际差||∞, ||预测差||∞, 1e-8)` 检查剩余残差。梯度分解和动量缓冲继续独立使用原检查，每一步写回舍入还必须满足上述上界。这样容许的原始绝对偏差随实际参数、更新量和已执行步数变化。六批的校正后最大相对残差为 `4.951e-6`。本次只评估了六个短程批次，采用该判据和核对长期误差累计仍待审查。
