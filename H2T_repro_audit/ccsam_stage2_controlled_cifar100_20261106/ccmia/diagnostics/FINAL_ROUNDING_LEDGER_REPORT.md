## 每一步写回舍入与独立验证

C2 和 C3 各有独立账本。capture 保存单臂 FP32 参数、梯度和前置动量。record 按实际 SGD 配置复算 coupled weight decay、首步缓冲初始化、后续动量和可选 Nesterov 更新方向，用真实动量缓冲核对 replay，然后以同设备、同 dtype 的 add_ 或 _foreach_add_ 独立重放参数写回。若缓冲或参数重放不同，立即抛错，账本保持未提交状态。

```text
R_C2 = W_after_C2_FP64 - (W_before_C2_FP64 - lr * U_C2_FP64)
R_C3 = W_after_C3_FP64 - (W_before_C3_FP64 - lr * U_C3_FP64)
delta_R = R_C3 - R_C2
cumulative_delta_R = sum_step(delta_R)
```

实际方向 U 来自该臂已验证的梯度、coupled weight decay、动量和 Nesterov 配置。账本 API 仅接收一个分类头及其 optimizer，独立于 paired reconstruction 函数和科学梯度分量。单元测试额外验证了禁止调用重构比较函数、实际写回被篡改时拒绝入账，以及科学 tracker 的原分量保持逐位相等。

## 算子语义与舍入上界

本地 PyTorch 的 optim/sgd.py 决定实际 SGD 更新方向。CUDA _foreach_add_ 的 BinaryOpListAlphaFunctor 在 ForeachFunctors.cuh 中以 opmath_type<T> 处理 alpha 和乘加，并将结果写回 T。对于 FP32，系数和算术工作精度均为 FP32。记录的原生 replay 覆盖了实际算子执行与写回。

取 u = finfo(dtype).eps / 2，s = finfo(dtype).tiny * finfo(dtype).eps，eta_d 为原生 dtype 中的学习率。使用实际操作数的幅度构造逐元素上界。s 采用一个最小非正规数间距，覆盖下溢舍入。

```text
q = abs(eta_d) * abs(U)
B_mul = u * q + s
B_coefficient = abs(eta - eta_d) * abs(U)
B_add = u * (abs(W_before) + q + B_mul) + s
B = B_coefficient + B_mul + B_add
require abs(R) <= B
```

上界同时覆盖分离乘加和合并乘加，学习率原生转换误差单独计入。六批最坏的单臂 abs(R)/B 为 0.9889021217。
