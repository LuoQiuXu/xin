## A. Scientific objective

The sealed C0/C1/C2 results showed that the original C1 feature-gradient perturbation improves Few but damages Many. C3 removed direct Many perturbations but did not recover Many accuracy; it retained the Few gain.

C4 is the first constructive full-method experiment:

- Module A: keep the complete original C1 CC-SAM feature-gradient perturbation on every class.
- Module B: use the corresponding seed's final C2 classifier as a frozen teacher and distill its full 100-class output distribution on Many-class original GAP features only.
- Student: initialize from the same Clean Stage-I classifier as C0-C3, never from the C2 teacher.
- Teacher: final epoch-30 C2 classifier for the matching Stage-II seed, frozen throughout.
- Backbone and BN: frozen.
- Objective: L_C4 = L_C1 + lambda_HP * L_HP.
- T=2.0, lambda_HP=1.0, fixed for this first run. No tuning or search.

Many means the sealed original TRAIN class count is strictly >100. Do not use class-ID ranges or validation counts. The KL input subset is Many-only, but the target distribution covers all 100 output classes.

## E. Frozen protocol

- CIFAR-100-LT IF=100, official TRAIN only, 10,847 samples.
- ResNet-32 Clean Stage I, seed 42, best epoch 184.
- 64-D GAP features through the existing clean_compatible_gap path.
- Seeds 123, 124, 125.
- Stage II: 30 epochs, batch size 64, 170 steps/epoch.
- SGD(lr=0.01, momentum=0.9, weight_decay=0.0002, nesterov=False).
- FP32 only. No AMP, MixUp, gradient accumulation, scheduler change, early stopping, or best-epoch selection.
- Same sealed sampling plan, augmentation transform, and continuous augmentation RNG as C1.
- Student initializes from the sealed Clean Stage-I classifier.
- Teacher is the same seed's final C2 checkpoint and is frozen.
- C1 perturbation remains active for Many, MediumN, and Few.
- Distillation uses original, unperturbed GAP features for Many samples only.
- The teacher and student both produce full 100-class logits.
- Primary result is fixed epoch 30.
- Official CIFAR-100 TEST is strictly prohibited. Never instantiate CIFAR100(train=False), open/decode the test pickle, or use test labels.

Only C4 is newly trained: 3 seeds ×30 epochs =90 epochs and 15,300 optimizer steps.
