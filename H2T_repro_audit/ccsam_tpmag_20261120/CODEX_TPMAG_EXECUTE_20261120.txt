The method is frozen:
- Only eligible non-Many source -> represented Many target direct perturbation-gradient components are gated.
- Head benefit is the first-order increase of the target Many fixed margin.
- Tail risk is the first-order decrease of the source class margin against the represented Many logit set.
- For a nonzero eligible pair, g = relu(head_benefit) / (relu(head_benefit) + relu(-tail_margin_shift) + 1e-12). An exactly zero pair gradient uses identity gate 1 because there is no contribution to suppress.
- Gate-distribution summaries use active nonzero eligible pairs; report the total eligible pair count separately.
- Clean CE gradients, feature perturbation, class weights, non-eligible pair components, backbone, optimizer and training schedule remain unchanged.
- No AMP. No threshold, epsilon, coefficient or reference tuning.

- Official CIFAR-100 TEST access is prohibited.
