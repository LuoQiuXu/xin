## Why the new source is different

1. `diagnostics/test_diagnostic_stats.py` now imports `.diagnose_b0` as a package-relative sibling, and `diagnostics/__init__.py` declares the package.
2. `validate_cpu.py` is the single CPU gate. It performs static protocol checks, py_compile of the complete source set, and all 41 CPU test methods; it writes `CPU_VALIDATION.json` and exact source fingerprints.
3. `preflight.py` checks the actual approved `models.FishModel` local 19c8e357 strict adapter. It does not call `ResNet50_FE`, does not call `pretrained=True`, and forbids `torch.hub.load_state_dict_from_url` during the adapter check.
4. Preflight verifies image bytes only for TRAIN and VAL (16,269 + 5,396 = 21,665). TEST rows are metadata-only: no TEST path resolution, stat, open or image-byte hashing. The report must show `test_image_bytes_read=0`.
5. Smoke no longer reads `CPU_TEST_RESULTS_FINAL.txt` or `ORIGINAL_SOURCE_HASHES.json`. It requires the current CPU/preflight JSON records, checks their HEAD/source fingerprints, and rejects dirty source.
6. The stale B0 expectation for an FP16 GradScaler overflow at batch 6 has been removed. In FP32 every non-finite gradient is fatal and optimizer skips must be zero.
7. Smoke manifests now explicitly record `amp=false`, `autocast_enabled=false`, `grad_scaler_enabled=false`, and the FP32 numeric mode.
