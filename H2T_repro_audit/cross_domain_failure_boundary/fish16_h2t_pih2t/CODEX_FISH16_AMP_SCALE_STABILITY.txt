0. DECISION — NO MORE BROAD AUDITS
======================================================================

The first formal run is preserved unchanged at:
  D:\h2t_cross_domain_results\fish16_formal_seed42_90x10_20261102_01

It completed A0 epochs 1-3 and stopped in A0 epoch 4, zero-based batch 976:
  one negative Inf at classifier.bias[0]
  no NaN, no missing gradients
  finite logits and loss (loss=0.962948381901)
  GradScaler scale=262144
  no scaler.step/update and no SGD update for the rejected window
  4,027 actual optimizer.step calls observed in the process

The default GradScaler doubled its scale after approximately 2,000 successful
updates: 65,536 -> 131,072 -> 262,144. The failure occurred after the second
growth. The earlier controlled B0 forensic report already proves that this
training stack can overflow an FP16 backward intermediate at excessive loss
scale while forward tensors remain finite. The exact internal source of the
A0 classifier.bias Inf was not directly instrumented; do not claim the A0 and
B0 overflows are the same internal operator.

The code correction is intentionally narrow:
  - retain FP16 autocast;
  - retain initial scale 65,536;
  - retain native GradScaler step/skip/backoff behavior;
  - set growth_interval=100,000 for the formal runner only;
  - leave amp_recovery.py and the smoke runner's scaler unchanged.
A 90-epoch Stage-I condition has at most 91,530 attempted windows
(90 * 1,017), so the scale cannot automatically grow during a condition.
If the allowed B0 PIF-b Inf occurs at 65,536, native GradScaler may back off to
32,768. The scale then remains there for the rest of that condition.

The correction branch also fixes a documented resume comparison defect:
JSON converts tuples in overflow records to lists. Epoch-record comparisons
must normalize both representations before comparison.

Do not add losses, clipping, gradient clamping, gradient replacement, lower
learning rates, different batch sizes, accumulation, BF16, FP32, a new backbone,
new data, or any H2T/PI-H2T algorithm changes.
