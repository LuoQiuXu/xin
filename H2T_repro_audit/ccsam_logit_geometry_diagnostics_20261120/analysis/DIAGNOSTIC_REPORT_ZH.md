# CC-MIA Logit Adjustment 与分类器几何离线诊断

在 Evaluation 的 61 个 τ 点上，C2 整条曲线支配 BASE_C3 的种子数为 **0/3**，反向支配为 **0/3**。逐点支配与干预点覆盖见下表。

Calibration 和 Evaluation 各有 990 张 TRAIN 派生开发样本，每个已覆盖类别 10 张。按原 TRAIN 频次计算，每个分区有 Many 340、Medium 350、Few 300 张。原任务书的 Medium 450、Few 200 已按封存计数更正。

父提交为 `1f2615098bea731a2702f74c26cd5918b0c2945b`。18 个本地分类头、3 份 logits 和 147 项封存依赖均通过 SHA256 检查。12 组 CPU 重算 logits 的最大绝对误差为 8.58e-06，与保存 logits 的 top-1 预测完全一致。训练更新和官方 TEST 访问均为 0。

几何分析以 C2 末轮分类器行为参考，使用父实验沿 BASE_C3 轨迹积分并经 SGD 动量传播的累计来源条件参数位移。

## 局限

1. 推断范围限于三个固定种子和两个 TRAIN 派生分区。历史 Stage-I 曾使用完整 1,980 张 holdout 选模。Many 只覆盖原 35 类中的 34 类，class 0 缺席。
2. Evaluation 峰值用于描述曲线。实际锁定结果来自 Calibration 选择的 τ。
3. 几何分解取决于 C2 末轮行的参考方向，刻画沿 BASE_C3 轨迹的累计参数归因。据此干预径向或切向分量的效果仍待验证。
