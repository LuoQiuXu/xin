THREE ARMS — NO OTHER GROUPS
----------------------------
A. BCL_ORIGINAL
   - Exact original BCL objective.
   - No reliability gate.
   - Use the existing BalancedContrastiveLoss implementation unchanged.

B. BCL_GLOBAL_RAW_MARGIN
   - For each training sample, compute v1 observed-label raw margin:
       m_i = z_i[y_obs] - max_{k != y_obs} z_i[k]
   - reliable_i = (m_i > 0).
   - Apply this gate only to BCL relationships, never to LC.

C. BCL_FEW_CLASS_ADAPTIVE_Q90
   - Many and Medium observed-label samples are always reliable.
   - For observed-Few samples, compute:
       s_i = (m_i - mu[y_obs]) / (sigma[y_obs] + 1e-8)
   - mu/sigma are the fixed per-observed-class Epoch-160 raw-margin
     statistics from gate_reference.json.
   - reliable_i = (s_i > few_q90_threshold).
   - few_q90_threshold is the score-only 90th percentile over the 1,536
     observed-Few normalized margins, written by Part 1.
   - This is a predeclared unlabeled-score threshold, not tuned using
     clean_label or is_clean. Do not optimize it after seeing source-attribution
     results.
   - At the Epoch-160 reference distribution it should retain approximately
     the top 10% of observed-Few samples (about 154/1536); log the actual
     acceptance rate during resumed training.

For reference, the existing audit threshold table reports the Few-group
class-normalized q90 threshold as approximately 1.1284409609. The script must
use the value generated by gate_reference.json, not hard-code this rounded
number.

  BCL prototypes = the original classifier-derived class prototypes

The gate must not alter:

  - observed noisy class counts used by LC prior;
  - model architecture, projection MLP, prototype generation;
  - three-view concatenation or BatchNorm behavior;
  - optimizer, momentum, weight decay, LR schedule.

For gated arms, implement a separate masked BCL loss in the new BCL_LTN
continuation script. Do not edit BCL_AUDIT/cifar100lt/losses.py.

Required relation semantics for every gated sample:
1. Every sample always retains its own v2-v3 positive pair, regardless of
   reliability. This is the self-supervised safeguard.
2. A reliable anchor may use reliable same-observed-label sample views as
   cross-sample positives.
3. An unreliable anchor must not use other samples as supervised positives.
4. Unreliable sample views must be removed from every OTHER anchor's candidate
   denominator; they must not silently become negatives.
5. The unreliable anchor's observed-class prototype connection must be removed
   from that anchor's denominator entirely: neither positive nor negative.
   Reliable anchors retain the original same-class prototype positive and all
   other class prototypes as negatives.
6. The original class-prototype computation/parameters remain unchanged.
7. Recompute per-anchor class-occurrence counts and denominator weights from
   the actually allowed candidate set, including the anchor itself in the
   class count before subtracting the positive indicator. Do not reuse the
   ungated global counts after masking.
8. Every anchor must have at least its own paired-view positive. All denominator
   weights must be finite and strictly positive wherever a candidate is active.

For each gated loss call, record:
  - reliable/unreliable sample counts by observed group;
  - self-view positive links;
  - cross-sample positive links;
