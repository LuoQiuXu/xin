IMPLEMENTATION
--------------
Create:
BCL_LTN/audit_epoch160_margin_reliability.py

The audit must:
A. Reuse BCL_LTN.train_noisy_bcl.load_verified_noise, OfficialTestAudit and
   safe_torch_load. Reuse BCL_AUDIT.cifar100lt.models.BCLCIFARModel and the
   audited state_dict_sha256 helper. No source changes in these modules.
B. Verify the checkpoint file SHA against training_summary.json, checkpoint
   epoch=160/seed=42, model-state hash against epoch_160.json, fixed-index SHA,
   noise-manifest SHA, and observed noisy class counts used by LC/BCL.
C. Create a TRAIN-only evaluation dataset that returns only (image, position).
   It must not return clean labels, noisy labels, or flip masks to the model.
   Do not instantiate CIFAR100LT before inference because its constructor
   materializes clean targets. Load only raw TRAIN pixels and the fixed index
   vector for the inference dataset; defer load_verified_noise until afterward.
D. Run exactly one deterministic eval-mode forward pass over all 10,847 fixed
   TRAIN images with the standard eval transform, batch size 256, num_workers 0.
   The model must remain in eval mode and its state hash must be identical
   before/after inference. No gradients or optimizer.
   Enforce FP32 inference, disable TF32, set cuDNN deterministic=True and
   benchmark=False; do not enable autocast.
E. Define each sample's margin against its OBSERVED noisy label y_obs:
      m_i = z_i[y_obs] - max_{k != y_obs} z_i[k]
F. Calculate four predeclared score variants:
   1. raw_margin: m_i from raw logits z.
   2. lc_plus_log_prior_margin: margin from z + log(pi), matching the exact
      LogitCompensatedCE training convention.
   3. inverse_prior_margin: margin from z - log(pi), a diagnostic hypothesis.
   4. class_normalized_raw_margin:
      (raw_margin - mean_margin[observed_class]) /
      (std_margin[observed_class] + 1e-8).
   pi must use observed noisy-label class counts, not clean counts.
   Class normalization must use observed class membership and score values
   only, never clean/noisy status.
G. Crucial grouping: report Many/Medium/Few by the OBSERVED LABEL's class
   frequency group (class groups defined from the original clean IF=100 class
   count vector). Do not group by original source class. Verify exact group
   totals and clean positives against the noise manifest:
      Many: 6752 total / 5237 clean / 1515 noisy
      Medium: 2559 total / 1037 clean / 1522 noisy
      Few: 1536 total / 194 clean / 1342 noisy
H. Treat clean/unflipped as positive and flipped/noisy as negative. Report:
   - pooled group ROC-AUC;
   - average precision (step-wise AP);
   - trapezoidal PR-AUC (label distinctly from AP);
   - stratified-bootstrap 95% CIs for these ranking metrics;
   - macro per-observed-class ROC-AUC/AP/PR-AUC within each group;
   - per-class metrics and sample counts.
I. Report threshold operating points at score > 0 and at score quantiles
   q10/q25/q50/q75/q90. Quantiles are computed from unlabeled scores only.
   For each point report precision(clean), recall(clean), noisy acceptance
   rate, clean rejection rate, TP/FP/FN/TN and selected count.
J. Generate:
   - margin_distributions.png (Many/Medium/Few x four score methods);
   - roc_pr_curves.png;
   - group_metrics.csv;
   - threshold_metrics.csv;
   - per_observed_class_metrics.csv;
   - sample_scores.csv (offline-only, contains clean truth; never commit);
   - audit_summary.json;
   - AUDIT_REPORT.md.
K. Add unit tests for target margin, log-prior signs, AUC/AP with ties,
   within-class normalization invariance, observed-label grouping, threshold
