If no EMA checkpoint exists in v1, explicitly label this audit as frozen-teacher initialization; do NOT call it EMA. Implement optional EMA teacher only as a separate v2 training component, not by relabeling a frozen checkpoint.
4. Do not open clean_labels, is_noisy, CIFAR test labels, validation labels, or any held-out truth while estimating T/pi. Add an audit hook/guard equivalent to TruthReadGate. The estimation stage must accept only (teacher_probabilities, observed_labels).

Save teacher probabilities, estimated T, estimated clean prior, gamma, row support, global diagonal retention, input hashes, checkpoint hash, posterior_kind, estimator hyperparameters and source hash in a compact JSON/NPZ receipt. Never commit image arrays, probability arrays, checkpoints, or NPZ outputs.

   - balanced_posterior: p_bal(c|x), multiply estimated pi exactly once in Bayes posterior;
