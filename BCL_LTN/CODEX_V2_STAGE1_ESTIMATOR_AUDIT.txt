## Implemented on this branch

1. BCL_LTN/noise_transition_estimator.py
   - T[c,j] = P(observed=j | clean=c).
   - Explicit balanced_posterior vs long_tailed_posterior semantics.
   - Data-driven initialization; no assumed eta/noise-rate prior.
   - Soft EM with max_iter=50, tolerance=1e-6 and actual convergence reporting.
   - Global empirical-Bayes template pools the highest-support 35% of supported classes by default; no absolute min-support=20 cutoff.
   - Tail rows shrink toward the empirical class-aware template, not a uniform KxK matrix.
   - Returns pi, T, gamma, effective support, high-support class IDs, iterations, convergence and final delta.
2. BCL_LTN/prepare_ntc_bcl_v2_noise.py
   - Sym-0.2 / 0.4 / 0.6, seed 42; Sym-0.4 must exactly reproduce the v1 observed-label SHA256.
   - Asym-0.4 uses a clearly named CIFAR-100 coarse-superclass cyclic fine-class mapping. Do not describe this as the only canonical asymmetric-noise definition.
   - CIFAR-100N real fine noisy_label, aligned to the previously audited fixed IF=100 TRAIN IDs.
   - Clean labels, flip masks and true matrices live only under each protocol's truth/ directory.
3. BCL_LTN/extract_v2_train_logits.py
   - Deterministic eval-transform logits in fixed indices-file order.
   - Reads TRAIN pixels only; does not load observed labels, clean-label sidecars, corruption masks or official TEST.
   - Validates checkpoint, model-state, indices and TRAIN source hashes.
4. BCL_LTN/audit_v2_transition_estimator.py
   - --phase estimate reads public manifest + observed labels + logits only.
   - It writes estimate_bundle.npz, estimator_only.json and seal.json before truth is accessed.
   - --phase evaluate verifies the seal first, then reads truth/ for offline scoring.
   - Reports T/pi errors, Many/Medium/Few q accuracy, prototype health and Soft-BCL positive/negative denominator diagnostics. No loss or training code is changed.

Use one unique output directory per regime. Example for Sym-0.4:

```powershell
  --phase estimate `
  --protocol-dir "BCL_LTN\outputs\ntc_bcl_v2_stage1_data_20261126\sym04" `

  --protocol-dir "BCL_LTN\outputs\ntc_bcl_v2_stage1_data_20261126\sym04" `

```

Repeat for sym02, sym06, asym04_coarse_cycle and cifar100n_real, changing only the protocol and output directory. Reuse the same frozen logits. Do not train one model per regime.

Important semantics:
- Primary: balanced_posterior = softmax(raw logits); multiply estimated clean pi exactly once in gamma.
- Sensitivity: long_tailed_posterior = softmax(raw logits + log observed noisy-label prior); do NOT multiply estimated clean pi again. This is an observed-prior proxy, not the true clean prior.
- q diagnostics: raw balanced q, estimated-clean-prior-calibrated q, and EM gamma.
- The clean labels and empirical/theoretical T may be opened only by --phase evaluate, after seal.json verifies the estimate bundle and estimator-only receipt hashes.
- Do not read is_noisy.npy; it is not needed for the offline scoring.
- No official CIFAR-100 TEST data or labels.

## Step 5 — report and stop conditions

For each regime, report:
- T Frobenius norm, MAE, diagonal-retention MAE and row-TV error.
- pi MAE/L1/L2/KL and Many/Medium/Few prior-mass error.
- Raw q / prior-calibrated q / gamma accuracy, NLL and entropy for Overall, Many, Medium, Few.
- Soft-BCL positive mass per anchor, negative inverse-denominator mass per anchor, denominator min/median/max and class-wise prototype positive/inverse-denominator mass. These are diagnostics only.
- Classifier row norms, prototype pairwise cosine and number of near-zero rows.
- EM iteration count, convergence flag, final delta, effective support and selected high-support class IDs.
- Synthetic theoretical-T error and empirical finite-sample-T error separately. CIFAR-100N has no theoretical T; use its empirical TRAIN transition as an offline reference only.
- State explicitly that the v1 epoch-200 teacher is weak on Few classes and was trained only on Sym-0.4. Cross-regime estimates are sensitivity results, not final model performance.

Stop / no-go if:
- EM fails to converge in 50 iterations or pi/T becomes non-finite/degenerate.
- Tail pi collapses to zero, transition rows lose mass, or gamma becomes non-finite.
- Checkpoint, indices, TRAIN, observed-label or CIFAR-100N cache hashes mismatch.
- The estimate phase accesses any truth file or official TEST.
- Probability semantics cannot be justified from the v1 LogitCompensatedCE objective.
