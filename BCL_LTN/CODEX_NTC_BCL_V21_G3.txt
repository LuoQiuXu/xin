## 2. Exact mathematical contract

### 2.1 Probability semantics

The deterministic EMA TRAIN pass returns:
p_bal(c|x) = softmax(ema_logits).

Do not add log_prior before this softmax. The existing
EstimatedTransitionForwardCorrection training objective uses
logits + log_prior; therefore the raw EMA softmax is the balanced-posterior
quantity used by the PiW step.

### 2.2 PiW-EstT with raw support (no Kish ESS)

For the first EM update (Epoch 20), use:
pi_ref = observed_counts / N.

For every later update, use the previous already-blended prior:
pi_ref = pi_blended_(t-1).

For each sample:
q_ic = p_bal_ic * pi_ref_c / sum_k(p_bal_ik * pi_ref_k).

Keep the existing visual confidence weight:
w_i = (((max_c p_bal_ic - 1/K) / (1 - 1/K)).clamp_min(0)) ** confidence_power
with confidence_power=2.0.

Then:
S_c = sum_i w_i * q_ic (raw soft support; do NOT compute Kish ESS).
C_cj = sum_i w_i * q_ic * 1[observed_i=j] / S_c.
lambda_c = S_c / (S_c + shrinkage_mass) with shrinkage_mass=10.0.
Use the existing high-support global transition template and row normalization.
Every T row must remain finite, non-negative, and sum to one.

Important: reference_prior is only used for this PiW anchor. Preserve the
original regularized EM prior step, including prior_pseudocount=1.0; do not
silently replace the EM initialization or multiply the clean prior twice.

### 2.3 Prior calibration and Safe Floor

Under the fixed newly estimated T_hat, first compute the original regularized
EM prior pi_EM with prior_pseudocount=1.0.

Then solve in float64:
min_pi KL(mu_obs || T_hat.T @ pi) + lambda_h * sum_c (pi_c - pi_EM_c)^2
subject to:
sum_c pi_c = 1, pi_c >= pi_min.

Defaults:
- lambda_h = 1.0
- prior_min = 3/N (prior_min_count=3)
- float64 L-BFGS
- max iterations 100 (150 allowed only if convergence tests require it)
- tolerance 1e-8
- blend calibrated pi and T with the unchanged transition_blend=0.35.

Check solver convergence, finite objective, simplex error, and lower-bound
constraints at every EM update. A failed calibration must stop the run; do not
silently fall back to an uncalibrated prior.

Terminology caution: the objective above contains a squared L2 tether
sum((pi-pi_EM)^2), not a Hellinger distance. Implement the exact written
objective and report it as constrained KL + L2 prior calibration. Do not
silently replace it with a different Hellinger formula or describe the L2 term
as a Hellinger distance.

### 2.4 Zero-intervention diagnostics

At each EM update, calculate from the same p_bal and observed labels only:
- f_top20: within each observed class, rank samples by max_c p_bal; take
  ceil(20% * n_class) highest-confidence samples (at least one); calculate
  the fraction whose argmax equals the observed class; macro-average over
  observed classes.
- f_top50: same procedure using ceil(50% * n_class).
- f_all_macro: all-sample observed-label fit rate, macro-averaged over
  observed classes.

These are diagnostics only. They must not affect T, pi, loss, optimizer,
EMA, or the update coefficient.

Save all three values in:
1. each history.jsonl row containing an em_update;
2. each corresponding em_snapshots/epoch_*.npz.

Each EM snapshot must also contain:
- reference_prior
- raw_em_prior (pi_EM)
- raw_em_transition (T_hat)
- calibrated_prior
- blended_prior
- blended_transition
- anchor_support (S_c)

For 200 epochs, with warmup 20 and interval 5, expect exactly 36 EM updates:
Epochs 20, 25, ..., 195.
