E. REQUIRED ANALYSES
--------------------

H1 — CLASS-LEVEL GAIN HETEROGENEITY
1. Use only the saved final epoch-200 TEST prediction archives. Do not run a
   new TEST forward.
2. Compute LC-only and BCL class accuracy for all 100 classes and
   delta_accuracy_pp = BCL - LC-only.
3. Report Many/Medium/Few class-level mean, median, standard deviation, IQR,
   minimum/maximum, and positive/zero/negative class counts.
4. Rank all 30 Few classes by gain. Report top 10 and bottom 10.
5. Do not label a distribution "bimodal" solely from visual inspection. Give
   the full per-class distribution and describe its shape conservatively.

H2 — MANY-EXPOSURE, CONFOUND CONTROL, AND PAIR-LEVEL DID
1. Bridge the 30 Few classes to the 1,050 Many-Few pairs with three distinct
   exposure fields:
   - binary: at least one Many class is a symmetric-union DINO Top-5 neighbor;
   - binary: at least one Many class shares the CIFAR-100 superclass;
   - continuous: maximum DINO cosine similarity from the Few class to any of
     the 35 Many classes.
   Keep DINO Top-5 and same-superclass exposure separate; do not merge them
   into one post-hoc definition.
2. For each Few class, attach:
   - LC-only TEST baseline accuracy;
   - BCL-minus-LC TEST accuracy gain;
   - training count and log(training count);
   - mean LC-only Tail-to-Head confusion rate across all Many targets;
   - mean BCL-minus-LC Tail-to-Head confusion change across all Many targets.
3. Class-level adjusted association:
   - outcomes: Few-class delta accuracy and Few-class mean Tail-to-Head
     confusion change;
   - exposures: maximum DINO similarity, DINO-neighbor flag, same-superclass
     Many-exposure flag;
   - control delta accuracy by LC-only baseline accuracy and log training count;
   - additionally control Tail-to-Head confusion change by LC-only baseline
     Tail-to-Head confusion rate;
   - report standardized multiple-regression beta and partial Spearman;
   - also report unadjusted Spearman as a sensitivity check because delta
     accuracy contains the LC-only baseline with a negative sign; explain
     mathematical-coupling/regression-to-mean sensitivity;
   - report 2,000-replicate Few-class bootstrap intervals and valid replicate
     counts;
   - explicitly state that 30-class bootstrap uncertainty is conditional on
     this trained seed and is not training-seed uncertainty.
4. Pair-level directional confusion:
   - C[a->b] = P(prediction=b | true=a);
   - report Head-to-Tail and Tail-to-Head separately;
   - delta C = BCL - LC-only;
   - report SameSuperclass and DINO symmetric-union Top-5 slices separately.
5. Baseline-confusion matching:
   - for each direction and relation, match every exposed pair with replacement
     to the nearest unexposed pair by LC-only baseline directional confusion
     rate;
   - report exposed/control pair counts, matched count, unadjusted DID,
     matched DID, baseline-confusion standardized mean difference before and
     after matching, and mean absolute matched baseline gap;
   - report confusion DID in percentage points; report raw/adjusted pair-margin
     DID in logit-margin units.
6. Pair bootstrap:
   - do NOT bootstrap the 1,050 pairs as if they were independent;
   - independently resample Many class IDs and Few class IDs with replacement;
   - pair weight = Many endpoint multiplicity x Few endpoint multiplicity;
   - recompute the baseline-confusion matching inside every replicate;
   - use 2,000 replicates and report valid replicate counts and percentile
     intervals;
   - explicitly label this a two-endpoint class-cluster bootstrap, not a
     training-seed confidence interval.
